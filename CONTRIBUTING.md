# Contributing

## What contributions should do

Improve project bootstrapping decisions with reproducible evidence. Keep the entry skill compact and put conditional detail in linked references. Preserve portability across operating systems, providers and user accounts.

For changes, state the concrete failure/use case, update relevant guidance, run `python -m unittest discover -s tests -v`, and record representative behavioral scenarios where decisions change. Do not claim package checks prove live runtime compatibility or third-party security.

Do not include secrets, personal workstation paths, copied proprietary material, or external packages without their licensing requirements. Describe inspected patterns with attribution rather than copying implementation. Submit bounded changes with observed validation and remaining limits. Contributions are under the repository's MIT license.
