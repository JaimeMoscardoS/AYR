# Security scope

This repository contains instructions and documentation, not a sandbox or a security scanner. Loading a skill can influence an assistant's actions; review it before use and preserve the host runtime's authorization rules.

Third-party candidates are treated as untrusted data until reviewed. Source/revision, referenced resources, executable behavior, permissions, network access and license must be assessed before activation. Static review and popularity cannot guarantee safety.

Report vulnerabilities through the repository's private vulnerability reporting feature when available, or an existing private channel to the owner. Do not place credentials or exploit-sensitive data in public issues. This project makes no claim of continuous security monitoring or a third-party certification.
