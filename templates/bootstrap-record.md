# Project bootstrap record

Use relevant fields only and integrate into existing documentation.

## What it is
Product, users, outcome, current state, scope and constraints.

## Structure and decisions
Chosen boundaries and why; alternatives; assumptions requiring verification.

## Capabilities
Need | skill/agent role | source + exact revision | license | permissions/data access | trust decision | runtime availability | validation.

For selected workflow skills, include phase/trigger, resolved entry point and resources, ready/recommendation-only/blocked status, input/output and handoff evidence.

## Workflow ownership
Chosen workflow owner, authoritative state/artifact paths, decisions carried forward and the next entry point. Reuse existing project planning rather than creating parallel state.

## Work order
Task | owner | owned paths | prerequisites | acceptance | handoff evidence.

## Verification and continuation
Commands run and observed results; pending checks/blockers; revision; next bounded task. Distinguish inspection, local checks, integration, and deployment.
